# Form Login — LUMIO POS Cloud POS

Halaman portal autentikasi & login resmi untuk **LUMIO POS** (Boba & Drinks POS).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `owner@lumio.id` (PIN: `778899`)
   - 💼 **Manajer Operasional**: `storehead@lumio.id` (PIN: `334455`)
   - 💳 **Kasir Shift**: `barista@lumio.id` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Lumio Boba Tebet, Lumio Mall Kelapa Gading, Lumio Serpong).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../lumio-cloud-pos/index.html`](../lumio-cloud-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
